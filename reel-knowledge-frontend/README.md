# 🌐 Reel Knowledge Frontend (mindmap)

> A modern, sleek web dashboard for browsing, searching, and organizing AI-enriched knowledge captured from Instagram Reels and web resources.

## ✨ Features

- **Intuitive Knowledge Dashboard**: Browse ingested reels and web resources in a sleek, responsive card grid.
- **Categorization & Taxonomy**: Filter content effortlessly across tech, design, AI, productivity, and personal categories with interactive category strips.
- **Semantic Vector & Full-Text Search**: Query your entire library conceptually using natural language queries powered by pgvector on the backend.
- **In-Browser Video Playback**: Direct streaming of reel videos with HTTP 206 range-request support.
- **AI Summary & Key Takeaways**: High-level synthesis, bullet points, and core takeaways generated by LLMs for fast skimming.
- **Audio Transcript Viewer**: Synchronized, readable audio transcripts extracted directly from reel audio.
- **Resource Linking**: Connect relevant websites, GitHub repos, or documentation articles to specific reels.
- **Item Health & Retry Management**: Identify incomplete or failed items and trigger immediate queue retries with a single click.

## 🚀 Getting Started

### 1. Prerequisites

- **Node.js** (v20+ recommended)
- **npm**, **pnpm**, or **yarn**
- Running instance of [reel-knowledge-backend](../reel-knowledge-backend) (default `http://localhost:3000/api`)

### 2. Installation

Clone the repository and install dependencies:

```bash
cd reel-knowledge-frontend
npm install
```

### 3. Configure Environment Variables

Create `.env.local` using the provided template:

```bash
cp .env.example .env.local
```

Set the backend API URL:

```env
NEXT_PUBLIC_API_URL=http://localhost:3000/api
```

### 4. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser to view the application.

## 📦 Production Build & Deployment

### Build Locally

```bash
# Compile and optimize for production
npm run build

# Start the production server on port 3001
npm run start
```

### Deploy to Vercel

The easiest way to deploy the frontend is via [Vercel](https://vercel.com):

1. Import this repository (or specify `reel-knowledge-frontend` as the Root Directory in Vercel project settings).
2. Set the Environment Variable:
   - `NEXT_PUBLIC_API_URL`: Your deployed backend API URL (e.g., `https://api.yourdomain.com/api`).
3. Deploy!
